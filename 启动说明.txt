电气控制虚拟仿真系统 — 本地启动说明
========================================

【最简单的用法】

双击本目录下的  start_server.bat  即可。

脚本会自动完成：
  1. 查找本机可用的 Python
  2. 自动挑一个没被占用的端口（默认 8000，被占用就自动 +1）
  3. 启动本地 HTTP 服务器
  4. 自动打开浏览器进入系统

要关闭服务：直接关掉那个黑色命令行窗口即可。


【重要提醒】

不要直接双击 index.html 打开！

本项目使用 ES Module（import / export），浏览器在 file:// 协议下
会拒绝加载这些模块，结果就是一片白屏。必须通过 HTTP 服务器访问。

用 start_server.bat 启动后，浏览器地址是 http://localhost:8000


【脚本为什么全是英文】

Windows 的 cmd.exe 对含有中文的 .bat 文件编码处理很不稳定
（UTF-8 带 BOM 会把 BOM 当成命令、GBK 视代码页而定），
为了确保双击一定能跑起来，脚本正文使用纯 ASCII 英文，
中文说明单独放在本文件里。


【如果提示找不到 Python】

本项目是纯前端项目，零依赖、零构建，不需要 Node.js 或数据库。
唯一需要的是一个"本地 HTTP 服务器"，这里用 Python 自带的
http.server 充当。

如果脚本报 "Python not found"：
  1. 去 https://www.python.org/downloads/ 下载安装
  2. 安装时务必勾选 "Add Python to PATH"
  3. 重新双击 start_server.bat


【手动启动（不想用脚本时）】

在本目录地址栏输入 cmd 回车，然后执行：

    python -m http.server 8000

浏览器访问 http://localhost:8000

端口被占用就换成 8080 等其它数字。


【想让局域网内其它电脑 / 手机也能访问】

本脚本已经绑定 0.0.0.0，服务默认对局域网开放。

  1. 查看本机内网 IP：命令行执行  ipconfig ，找 IPv4 地址
     （一般是 192.168.x.x 或 10.x.x.x）
  2. 让其它设备浏览器访问  http://你的IP:8000
     例如 http://192.168.1.100:8000
  3. 如果访问不了，检查 Windows 防火墙是否放行了该端口，
     或首次弹窗时选择"允许访问"

课堂场景下比较实用：老师在教师机启动，学生用自己电脑或
平板打开同一个地址即可。


【浏览器要求】

需要支持 ES Module 的现代浏览器：
Chrome / Edge / Firefox / Safari 较新版本。

其中的 3D 十字工作台视窗需要 WebGL 支持。


【常见问题】

Q: 端口自动跳到了 8001 而不是 8000？
A: 说明 8000 已被别的程序占用，脚本自动换了一个，属正常行为。
   看脚本输出的 "Open this : http://localhost:xxxx" 用那个地址即可。

Q: 页面打开后是白屏？
A: 几乎可以肯定是没走 HTTP 服务器，而是直接双击了 index.html。
   请改用 start_server.bat。

Q: 改了配置或源码后要重新启动吗？
A: 不用。本项目无构建步骤，改完配置 JSON 或 JS 源码，
   直接在浏览器按 Ctrl+F5 强制刷新即可。
